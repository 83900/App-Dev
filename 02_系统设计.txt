WanderLog 旅行手帐应用 - 系统设计文档
===========================================

系统架构设计
-----------

1. 整体架构
   采用MVVM（Model-View-ViewModel）架构模式：
   
   View Layer (UI层)
   ├── Activities/Fragments
   ├── Compose UI组件
   └── 自定义View组件
   
   ViewModel Layer (视图模型层)
   ├── 业务逻辑处理
   ├── 数据绑定
   └── 状态管理
   
   Model Layer (数据层)
   ├── Repository (数据仓库)
   ├── Local Database (本地数据库)
   ├── Remote API (远程接口)
   └── SharedPreferences (配置存储)

2. 技术栈选择
   - 开发语言：Kotlin
   - UI框架：Jetpack Compose + 传统View
   - 数据库：Room + SQLite
   - 网络请求：Retrofit + OkHttp
   - 图片处理：Glide
   - 依赖注入：Hilt
   - 异步处理：Coroutines + Flow
   - 导航：Navigation Component

数据库设计
----------

1. 旅行表 (trips)
   ```sql
   CREATE TABLE trips (
       id INTEGER PRIMARY KEY AUTOINCREMENT,
       title TEXT NOT NULL,
       description TEXT,
       start_date INTEGER NOT NULL,
       end_date INTEGER NOT NULL,
       budget REAL DEFAULT 0,
       actual_cost REAL DEFAULT 0,
       cover_image TEXT,
       created_at INTEGER NOT NULL,
       updated_at INTEGER NOT NULL
   );
   ```

2. 旅行日记表 (diary_entries)
   ```sql
   CREATE TABLE diary_entries (
       id INTEGER PRIMARY KEY AUTOINCREMENT,
       trip_id INTEGER NOT NULL,
       title TEXT NOT NULL,
       content TEXT,
       location_name TEXT,
       latitude REAL,
       longitude REAL,
       weather TEXT,
       mood INTEGER DEFAULT 0,
       rating INTEGER DEFAULT 0,
       entry_date INTEGER NOT NULL,
       created_at INTEGER NOT NULL,
       updated_at INTEGER NOT NULL,
       FOREIGN KEY (trip_id) REFERENCES trips(id) ON DELETE CASCADE
   );
   ```

3. 媒体文件表 (media_files)
   ```sql
   CREATE TABLE media_files (
       id INTEGER PRIMARY KEY AUTOINCREMENT,
       diary_entry_id INTEGER,
       trip_id INTEGER,
       file_path TEXT NOT NULL,
       file_type TEXT NOT NULL,
       file_size INTEGER DEFAULT 0,
       caption TEXT,
       created_at INTEGER NOT NULL,
       FOREIGN KEY (diary_entry_id) REFERENCES diary_entries(id) ON DELETE CASCADE,
       FOREIGN KEY (trip_id) REFERENCES trips(id) ON DELETE CASCADE
   );
   ```

4. 费用记录表 (expenses)
   ```sql
   CREATE TABLE expenses (
       id INTEGER PRIMARY KEY AUTOINCREMENT,
       trip_id INTEGER NOT NULL,
       category TEXT NOT NULL,
       amount REAL NOT NULL,
       currency TEXT DEFAULT 'CNY',
       description TEXT,
       expense_date INTEGER NOT NULL,
       created_at INTEGER NOT NULL,
       FOREIGN KEY (trip_id) REFERENCES trips(id) ON DELETE CASCADE
   );
   ```

5. 地点表 (places)
   ```sql
   CREATE TABLE places (
       id INTEGER PRIMARY KEY AUTOINCREMENT,
       trip_id INTEGER NOT NULL,
       name TEXT NOT NULL,
       address TEXT,
       latitude REAL,
       longitude REAL,
       category TEXT,
       visit_date INTEGER,
       notes TEXT,
       rating INTEGER DEFAULT 0,
       created_at INTEGER NOT NULL,
       FOREIGN KEY (trip_id) REFERENCES trips(id) ON DELETE CASCADE
   );
   ```

API设计
-------

1. 本地API接口
   ```kotlin
   interface TripDao {
       @Query("SELECT * FROM trips ORDER BY start_date DESC")
       fun getAllTrips(): Flow<List<Trip>>
       
       @Insert
       suspend fun insertTrip(trip: Trip): Long
       
       @Update
       suspend fun updateTrip(trip: Trip)
       
       @Delete
       suspend fun deleteTrip(trip: Trip)
   }
   ```

2. Repository接口
   ```kotlin
   interface TripRepository {
       fun getAllTrips(): Flow<List<Trip>>
       suspend fun getTripById(id: Long): Trip?
       suspend fun insertTrip(trip: Trip): Long
       suspend fun updateTrip(trip: Trip)
       suspend fun deleteTrip(trip: Trip)
   }
   ```

3. 外部API接口（可选）
   - 天气API：获取历史和实时天气数据
   - 地图API：地理编码和反地理编码
   - 云存储API：数据备份和同步

UI/UX设计规范
------------

1. 设计原则
   - Material Design 3规范
   - 简洁直观的界面
   - 一致的交互体验
   - 无障碍访问支持

2. 颜色方案
   - 主色调：蓝色系（代表旅行和探索）
   - 辅助色：橙色系（代表活力和冒险）
   - 中性色：灰色系（用于文本和背景）
   - 状态色：绿色（成功）、红色（错误）、黄色（警告）

3. 字体规范
   - 标题：24sp, Bold
   - 副标题：20sp, Medium
   - 正文：16sp, Regular
   - 说明文字：14sp, Regular
   - 小字：12sp, Regular

4. 间距规范
   - 页面边距：16dp
   - 组件间距：8dp, 16dp, 24dp
   - 内容间距：4dp, 8dp

5. 组件规范
   - 按钮：圆角8dp，最小高度48dp
   - 卡片：圆角12dp，阴影2dp
   - 输入框：圆角8dp，边框1dp
