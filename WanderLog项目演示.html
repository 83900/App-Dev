📋 项目概述

🎯 项目愿景

WanderLog是一款专为旅行爱好者设计的手帐应用，提供从旅行规划到回忆分享的完整旅行记录解决方案。通过现代化的Android技术栈，为用户打造流畅、美观、功能丰富的旅行记录体验。

👥 目标用户

🧳

旅行爱好者

热爱旅行的年轻人群（18-35岁），需要完整的旅行记录工具

📝

记录达人

喜欢记录和分享生活经历，注重旅行回忆保存的用户

📊

规划专家

需要旅行规划和预算管理工具，追求高效旅行的用户

🚀 核心功能展示

🗺️

旅行规划

创建旅行计划，添加目的地和行程安排，支持时间线管理和预算设置

  • 智能行程规划
  • 预算管理系统
  • 目的地推荐
📝

旅行日记

记录旅行见闻，支持富文本编辑，心情记录和评分系统

  • 富文本编辑器
  • 心情和评分
  • 天气记录
📸

照片管理

上传和管理旅行照片，支持位置标记和智能分类

  • 自动位置标记
  • 照片编辑功能
  • 智能相册分类
💰

费用统计

记录旅行支出，生成详细的费用报告和预算分析

  • 多币种支持
  • 分类统计
  • 预算对比分析
📍

地图集成

显示旅行路线和地点标记，支持离线地图和导航功能

  • 实时定位
  • 路线规划
  • 景点推荐
📤

分享导出

生成精美旅行卡片，支持多种分享方式和格式导出

  • 精美模板
  • PDF导出
  • 社交分享

🛠️ 技术架构

🎨 UI层 - 地图展示

MapView + 自定义Marker + 交互控件

🔧 业务层 - 位置服务

LocationManager + GeocodeService + RouteService

📡 数据层 - 地图SDK

高德地图SDK + GPS服务 + 网络定位

地图SDK：高德地图 Android SDK v9.0+
定位服务：高德定位SDK + Android Location API
地理编码：Geocoding API + 逆地理编码
路线规划：Route Planning API + 多种出行方式

🏗️ 技术架构设计

MVVM + Repository 架构模式

🎨 Presentation Layer (表现层)

Jetpack Compose + 传统View

Activities, Fragments, ViewModels, UI Components

🔧 Domain Layer (领域层)

业务逻辑处理

Use Cases, Business Entities, Repository Interfaces

📊 Data Layer (数据层)

数据管理

Repository Implementation, Local Database, Remote API

🗄️ Storage Layer (存储层)

Room + SQLite + SharedPreferences

Local Database, File Storage, Configuration Storage

🛠️ 核心技术栈

开发语言：Kotlin 1.9.10+
UI框架：Jetpack Compose + 传统View
架构模式：MVVM + Repository Pattern
数据库：Room + SQLite
网络请求：Retrofit + OkHttp
依赖注入：Hilt (Dagger)
异步处理：Coroutines + Flow
图片加载：Glide
导航框架：Navigation Component
地图服务：高德地图SDK
